## 📌 About The Project

Sandhi is a Full Stack AI-Powered Recruitment Platform that automates resume screening, ATS compatibility analysis, skill extraction, candidate ranking, and intelligent job matching using Machine Learning and NLP.

The platform helps recruiters identify the most suitable candidates while providing job seekers with resume insights, ATS scores, and personalized job recommendations.

---

## ✨ Core Features

### 👨‍💼 Candidate Portal

- User Registration & Login
- Resume Upload (PDF / DOCX)
- Resume Analysis Dashboard
- ATS Compatibility Checker
- AI Job Recommendations
- Application Tracking
- Daily Job Application Streak

### 🏢 Recruiter Portal

- Job Posting Management
- Candidate Application Review
- Resume Screening Automation
- Candidate Ranking System
- Recruitment Analytics

## 🤖 AI Modules

### Resume Skill Extraction

Automatically extracts skills such as:

- Python
- Java
- React
- Node.js
- FastAPI
- TensorFlow
- MongoDB
- AWS
- Docker

---

### ATS Compatibility Checker

Evaluates:

- Keyword Coverage
- Resume Structure
- Formatting Quality
- Missing Skills

Provides:

- ATS Score
- Resume Feedback
- Improvement Suggestions

---

### AI Job Matching Engine

Uses:

- TF-IDF Vectorization
- Cosine Similarity
- NLP Processing

Outputs:

- Match Percentage
- Candidate Compatibility Score
- Recommended Jobs

---

### Resume Quality Analyzer

Analyzes:

- Skill Coverage
- Section Completeness
- Contact Information
- Achievements
- Resume Structure

Provides personalized recommendations for resume improvement.

---

## 🔥 Unique Innovation

### Streak-Based Job Application System

Unlike traditional job portals, Sandhi includes a gamified engagement mechanism.

Features:

- Daily Application Tracking
- Current Streak
- Longest Streak
- Total Applications
- Engagement Analytics

This encourages consistent job-seeking behavior and increases platform engagement.
